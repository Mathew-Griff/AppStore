# To-Do

A simple iPhone-style to-do list. It's a web app, so there's nothing to install from the App Store — you add it to your home screen and it opens full screen like a normal app. Tasks are saved on the phone and it works offline.

## Put it on your iPhone

1. On GitHub, open this repo → **Settings → Pages**.
2. Under *Build and deployment*, set **Source** to "Deploy from a branch", choose **main** and **/ (root)**, then **Save**.
   (GitHub Pages on a private repo needs a paid GitHub plan. If it isn't offered, make the repo public, or host it free on Netlify / Cloudflare Pages.)
3. After a minute GitHub shows the site address, e.g. `https://mathew-griff.github.io/AppStore/`.
4. Open that address in **Safari** on your iPhone, tap **Share → Add to Home Screen**.

## Using it

- Tap **New Reminder** to add a task, type, tap **done**.
- Tap the circle to tick it off.
- Swipe a task left to delete it.
- **Clear Completed** removes all ticked tasks.
- Follows your phone's light/dark mode.
